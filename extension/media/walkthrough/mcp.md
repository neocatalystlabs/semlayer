## Hand it to an agent

The layer is what lets an agent pick the right table, avoid the join that fans
out, and apply the filter nobody wrote down.

**semlayer: Connect an MCP client** writes the config for Claude Code, Cline,
Cursor or Claude Desktop — merging one entry in and leaving every other server
alone. Restart the client afterwards.

That is the only place MCP appears. MCP is how the *agent* reads the layer;
this extension talks to the CLI directly.
